Mesh anatomy

What a model file holds, as glTF stores it and Bevy loads it.

Structure

mesh
└─ primitive            one or more; one per material
   ├─ vertex table      rows = vertices, columns = attributes
   ├─ index list        three integers per triangle, each a row number
   └─ material          exactly one

Attributes

glTFBevy constantAlso calledTypeHoldsIf missing
POSITIONATTRIBUTE_POSITIONvertex positionvec3Location in metresNo shape
NORMALATTRIBUTE_NORMALnormalvec3Unit direction the surface faces; drives lightingEngine must compute flat normals: faceted look
TEXCOORD_0ATTRIBUTE_UV_0UVvec2Point on the texture image for this vertexTextures cannot be placed
TANGENTATTRIBUTE_TANGENTtangentvec4Needed for normal maps (later lesson)Engine should compute them (MikkTSpace)
COLOR_0ATTRIBUTE_COLORvertex colourvec3/4A colour per vertex, multiplied into the surfaceNone used

Rules of thumb

FactConsequence
A vertex is a whole row of attributesSame position with a different normal or UV is a second vertex
A sharp edge needs two normals along itHard edges add vertices; a hard-edged cube has 24, not 8
A cut in the UV layout needs two UVs along itUV cuts add vertices
A closed, fully shared surface of T triangles has T/2 + 2 verticesVertices far above that mean many splits
A primitive has one materialEach extra material is another primitive, drawn separately

Inspect a file

python3 learn/assets/glb_inspect.py <file.glb>

Prints each primitive's attributes, vertex count, triangle count and material. For measurements, see Measuring a model.
